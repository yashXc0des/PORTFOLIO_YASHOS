# Cat Animation Assets

See the full guide in **`public/lottie/README.md`**

## Quick pick

| You have… | Set `mode` to | Put file in |
|-----------|---------------|-------------|
| Lottie JSON from LottieFiles | `"lottie"` | `public/lottie/cat-walk.json` |
| Pixel art sprite sheet PNG | `"spritesheet"` | `public/sprites/cat-walk-sheet.png` |
| Animated GIF | `"gif"` | `public/sprites/cat-walk.gif` |
| Nothing yet | `"pixel"` | (built-in cat) |

Edit **`src/components/Pet/catConfig.ts`** to switch modes.
